# Ustalenia z partii próbnej (01, dwubój) — stosuj tak samo

Uzupełnienie INSTRUKCJA.md. Chodzi o spójność między partiami.

## Wnioski o propozycjach reguł (często błędne — sprawdzaj)

- Pozycje z Catalyst często mają progresję „masa ciała”, skok 0 i pusty
  sprzęt — prawie zawsze to sztanga: `kg`, 2,5, `["sztanga"]` (chyba że
  nazwa mówi inaczej: dumbbell, kettlebell, band, medball…).
- „Hang” to zawieszenie sztangi/hantla (pozycja startowa), nie zwis —
  progresja `kg`, nie `czas`. Zwis na drążku to „Dead Hang”, „Passive Hang”.
- „Behind the Neck” (BTN) to wyciskanie/podrzut zza karku, nie mobilność.
- „Grip” (Clean-Grip, Snatch-Grip, Hammer Grip, Neutral Grip) to chwyt —
  nie przedramię. Kategoria wg ruchu.
- Słowa clean/snatch w nazwie nie przesądzają o kategorii: Snatch-Grip Row
  → Upper pull horizontal, Clean-Grip Upright Row → Upper pull vertical,
  Snatch Push Press / Press in Clean / Sots Press → Upper push vertical.
- „Dip” w podrzucie (Jerk Dip, Rhythm Dip) to ugięcie nóg, nie dipy na poręczach.
- „Lift-Off”, „Bench/Staircase Pull” — nie jednostronne.
- 1DB/1KB **trzymany oburącz** (goblet, „1DB Push Jerk” z hantlem w obu
  rękach) → jednostronne `nie`. Jednostronne dopiero, gdy pracuje jedna
  ręka/noga albo ciężar jest w jednej ręce przy ruchu tej ręki.
- Część kompleksów reguły przepuszczają jako „pewne” (np. „Curtsy to Lateral
  Lunge to Clean and Press”) — każde „A to B to C” z różnymi ćwiczeniami to KOMPLEKS.
- „1"” przed nazwą (1" Power Clean) = start 1 cal nad podłogą (wariant floating) → 0,5.

## Decyzje wspólne

- **Pauza / tempo / 1.5 / segment** przy boju głównym ze sztangą: coeff jak bój
  bazowy (precedens BAZY: Bench press paused 3sec = 1, Barbell low bar squat
  paused 3sec = 1). Przy pozostałych ćwiczeniach też jak wersja bazowa.
- **Kompleks**: kategoria wg części, która ogranicza ciężar (np. przysiad +
  podrzut → Upper push vertical); `rodzaj` = `kompleks`; coeff wg
  najcięższego elementu, ale nie 1 (najwyżej 0,75), chyba że to klasyczny
  bój dwuboju (Clean & Jerk).
- **Upright row** (sztanga, hantle, wyciąg, kettlebell): Upper pull vertical, 0,5.
- **Szrugsy**: Upper pull vertical, 0,25, kod KATEGORIA.
- **RDL / stiff-legged / good morning ze sztangą**: RDL = 1 tylko klasyczne
  „BB Romanian Deadlift” (precedens BAZY); pozostałe warianty RDL ze sztangą
  (staggered, deficit, snatch-grip, pause) 0,75; z hantlami/kettlebellem 0,75;
  jednonóż 0,5–0,75 wg obciążenia. Good morning ze sztangą 0,75.
- **Carry** (farmer, suitcase, overhead, racked, waiter): Core, 0,75,
  progresja `dystans`, skok 0 (precedens BAZY: Suitcase carry).
- **Precedensy jednostronności** z INSTRUKCJA.md obowiązują (side plank,
  Copenhagen, suitcase carry, kickback pośladka, landmine rotations, bird dog,
  dead bug → `nie`).
